# mudmonkeys

A small vanilla PHP website for the mudmonkeys running group.

## Pages

- Home: `/`
- Calendar: `/calendar`
- About: `/about`
- Join: `/join`
- Contact: `/contact`

Set `CONTACT_EMAIL` in `.env` to show a direct email link on the Contact page.

## Run with Docker

```bash
docker compose up --build
```

Then open <http://localhost:8080>.
